# Security & Safety Invariant Rules

1. **Human Approval Gate Invariant:**
   - No remediation action may execute without explicit verification of an `ApprovalDecision` record signed with a valid HMAC-SHA256 signature.
   - The backend `ExecutionEngine` must enforce this invariant independently of frontend state.
2. **Zero Direct Execution of LLM Output:**
   - Raw strings generated by LLMs must never be passed directly to `subprocess`, `os.system`, `exec`, or `eval`.
   - Tool calls must accept only strictly typed enum arguments from a pre-approved allowlist.
3. **Prompt Injection Boundary:**
   - Ingested log payloads, URLs, command-lines, and user agent strings must be enclosed in XML isolation tags `<telemetry_payload>` and sanitized.
4. **Secret Isolation:**
   - Never commit API keys, tokens, or passwords to version control.
   - All credentials must be loaded through `pydantic_settings.BaseSettings` from `.env`.
5. **Tamper-Evident Audit Ledger:**
   - Every state change must write an immutable `AuditEvent` with cryptographic previous-hash chaining.
